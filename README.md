# Hi there 👋 I'm lex

Builder in Tokyo. I run a film photography contest community and build tools for the Salesforce ecosystem — mostly on Cloudflare Workers, mostly in TypeScript.

- 📷 **[Neoanaloglab Foto](https://foto.neoanaloglab.com)** — a weekly film photography contest community: submissions, anonymous voting, and results, end to end on Cloudflare Workers + D1
- ⚡ **[lightning-flow-scanner](https://github.com/lexluthor0304/lightning-flow-scanner)** — Salesforce Flow analysis engine (CLI / VS Code / GitHub Action), 20+ rules with auto-fixes
- 🎞️ **[NegativeConverter](https://github.com/lexluthor0304/NegativeConverter)** — turn scanned film negatives into positives, in the browser
- 🔗 [tokugai.com](https://tokugai.com)
